Операція «Архітектор Текстів»

Вітаємо у цифровій редакції «НУШ-Медіа»! Через критичний збій система керування документами заблокувала макет нового випуску. Твоє завдання — пройти 5 терміналів перевірки та відновити доступ.

Правило оцінювання: ти стартуєш із максимумом у 12 балів. Кожна невдала спроба перевірки або відкрита підказка знімає 0.5 бала.

Термінал 1/5: Класифікація ПЗ

Підбери правильний тип системи опрацювання текстів для кожного робочого завдання редакції:

Підказка (§ 2.1, с. 42): Прості тексти та код пишуть у текстових редакторах; формули верстають у LaTeX/MathType; макети для поліграфії — у видавничих системах; скан-копії перетворюють на текст за допомогою OCR.

Термінал 2/5: Об'єкти текстового документа

У макеті збилися налаштування форматування. Визнач, якому об'єкту документа належить кожен набір властивостей:

Підказка (§ 2.1, табл. 2.1): Шрифт і накреслення стосуються окремого символу; відступи та міжрядкові інтервали — абзацу; поля та орієнтація — сторінки; обтікання текстом — малюнка.

Термінал 3/5: Архітектура форматів файлів

Обери один формат файлу, який ідеально відповідає умові задачі:

TXT
Тільки текст без форматування
PDF
Стандарт обміну електронними документами
ODT
Стандарт для LibreOffice / OpenOffice
RTF
Кросплатформний обмінний формат
DOCX
Сучасний стандарт MS Word
TXT
Простий текстовий файл
Підказка (§ 2.1, табл. 2.2): PDF зберігає вигляд документа незалежно від пристрою та ОС. DOCX є стандартним форматом Word із високим рівнем стиснення (до 70%).

Термінал 4/5: Режими перегляду документа

Редакторам потрібно швидко виконати три дії. Обери режим перегляду (вкладка Подання) для кожної з них:

Підказка (§ 2.1, табл. 2.3): Ієрархію заголовків показує Структура; спрощений текст без форматування сторінки — Чернетка; вигляд для принтера — Макет друку.

Термінал 5/5: Синхронне звіряння версій

У редакції відкрито два файли: стаття_чернетка.docx та стаття_фінал.docx. Клікай по діях у правильному порядку, щоб розмістити їх поруч на одному екрані та порівняти:

Обрати в списку відкритих документів потрібний файл для порівняння Клікни
Перейти на вкладку «Подання» у стрічці текстового процесора Клікни
Прокрутити текст із увімкненою кнопкою «Синхронне прокручування» Клікни
У групі «Вікно» натиснути кнопку «Переглянути поруч» Клікни
Підказка (§ 2.1, с. 46): Алгоритм: 1) Вкладка Подання → 2) Група Вікно → Переглянути поруч → 3) Вибір другого документа зі списку → 4) Синхронне прокручування.
